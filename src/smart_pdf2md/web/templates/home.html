{# How it works #}

Cách hoạt động

Bốn bước từ PDF đến Markdown sạch.

  1. 1

    Tải PDF lên

    Kéo thả hoặc chọn file, tối đa 50 MB mỗi lần.

  2. 2

    Chọn trang cần chuyển

    Chọn tất cả, chỉ trang OCR, hoặc gõ range như 1-3,5.

  3. 3

    Chạy OCR / VLM

    Backend opencode hoặc paddleocr — ước tính FGold trước khi chạy.

  4. 4

    Tải Markdown

    Theo dõi tiến trình realtime rồi tải kết quả khi xong.

{# Features #}

Tính năng

Công cụ thực dụng cho pipeline PDF → Markdown.

Cache OCR theo trang

Chạy lại không tốn FGold cho trang đã xử lý khi bật cache.

Chọn trang linh hoạt

Preset Tất cả / OCR / Text, hoặc khoảng 1-3,5.

Theo dõi realtime (SSE)

Thanh tiến trình, ETA và log retry cập nhật trực tiếp trên trang job.

Nhiều backend

opencode (VLM) và paddleocr — chọn model và DPI phù hợp tài liệu.

Ước tính trước khi chạy

Biết trước FGold, thời gian và USD ước tính trước khi bắt đầu.

Hệ thống FGold

Giữ / trừ theo trang OCR; quản trị có thể nạp FGold cho người dùng.

{# FAQ #}

Câu hỏi thường gặp

smart-pdf2md hỗ trợ loại PDF nào? ▾

Cả PDF scan (cần OCR) và PDF có lớp chữ. Hệ thống đánh dấu trang cần OCR để bạn chọn nhanh.

FGold được tính như thế nào? ▾

Chủ yếu theo số trang cần OCR. Trang đã có trong cache (khi bật Dùng cache trang OCR) không bị trừ lại.

Có cần cài thêm phần mềm không? ▾

Không — dùng web UI trong trình duyệt. Đăng ký, tải PDF, chọn trang và tải Markdown về.

Giới hạn kích thước file? ▾

Mỗi lần tải lên tối đa 50 MB, một file PDF mỗi lần.
